# Express.js Practice & Fundamentals

In this repository, I practiced the basic concepts of Express.js, including routing, parameters, and query handling. Here, I did hands-on learning with Node.js and Express to set up servers and handle HTTP requests.

---

## 📂 File Structure & Contents

* **`index.js`**: Basic Express server setup, root routing (`/`), specific fruit routes (`/apple`, `/mango`, `/banana`), and custom 404 error handling for non-existent paths.

* **`index2.js`**: Advanced routing concepts including route parameters (`/:username/:id`) and query string handling (`/search?q=...`).

* **`package.json`**: Project configuration file tracking dependencies (Express v5) and scripts.
